# Storm Disasters

A local s&box add-on targeting stock Sandbox Mode. From the repository root on NixOS, run `./launch.sh --addon` to refresh the shared tornado assets and open the add-on. Otherwise, run `node tools/sync-storm-disasters.cjs` from the repository root and open `Addons/StormDisasters/storm_disasters.sbproj` in s&box. Play Sandbox’s `scenes/sandbox.scene` to play on stock Flatgrass.

Hold **Q → Entities → Disasters** and aim at open ground before choosing **Rope Tornado**, **Funnel Tornado**, or **Wedge Tornado**. Press **Z** to undo the most recent spawn. These are stationary visual effects: a depth-clipped funnel with a cloud cap, a spreading ground-dust skirt, and shaded airborne fragments. They apply no wind forces or damage and have no audio. Sprites are the fallback if the funnel shader is unavailable. The add-on does not require the Storm Chasers map and is not published to the Workshop.

The generator copies the game’s funnel and debris shaders and reads the game’s F1/F2/F5 heights, rope and cone width scales, rope/cone/walk-in wedge radii, and wedge eye radius. The add-on uses those values at 15% of the game’s display scale. Its local dust, animation settings, noise texture, and Sandbox integration live in `tools/storm-disasters/StormDisasterFunnel.csx.in`; do not edit generated `.csx` or shader files directly. Storm Chasers’ random weather, routes, audio, and other game logic are not synced. Regenerate the add-on files before committing a shared change, and sync before publishing the separately versioned add-on.

From the repository root, `node --test Tests/StormDisastersSync.test.cjs` checks synchronization and `node Addons/StormDisasters/Tests/check-layout.cjs` checks all three entry/prefab links. On Flatgrass, run `Tests/VolumeSmoke.cs.txt` through the editor's `run_csharp` tool to check the shader and dust without touching the player's undo stack. In your own Play session, run `Tests/FlatgrassSpawnSmoke.cs.txt` to exercise stock spawn and undo for all three entities. Do not run that test while someone else is spawning items in the same session.
