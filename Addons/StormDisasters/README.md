# Storm Disasters

A local s&box add-on targeting stock Sandbox Mode. From the repository root on NixOS, run `./launch.sh --addon` to refresh the shared tornado assets and open the add-on. Otherwise, run `node tools/sync-storm-disasters.cjs` from the repository root and open `Addons/StormDisasters/storm_disasters.sbproj` in s&box. Play Sandbox’s `scenes/sandbox.scene` to play on stock Flatgrass.

Aim at open ground, then hold **Q → Entities → Tornadoes** to spawn a preset. The add-on also ships a grouped native spawnlist. **Cone**, **Cylinder**, **Hourglass**, **Rope**, **V-shaped**, and **Wedge** each have six separately spawnable entries, **F0–F5**. Higher ratings make that shape taller and wider. Each tornado follows a curving, variable-speed path and stays near the ground. Press **Z** to undo the most recent spawn. Tornadoes apply no wind forces or damage. Sprites are the fallback if the funnel shader is unavailable. The add-on does not require the Storm Chasers map and is not published to the Workshop.

The tornado’s condensation lowers from a forming wall cloud, bends as it travels, then lifts and fades before the object expires. While at least one tornado is active, the map gets shared overcast, wind-driven rain, and a mix of wind, rain, covered rain, and a spatial tornado roar. Rain is suppressed under cover. The weather stops when the last tornado is removed or expires. Fog, automatic spawning, intensity upgrades, map-specific routes, and ground scarring are not part of the add-on yet. Storm Chasers does not depend on Storm Disasters yet.

The generator copies the game’s funnel and debris shaders, bakes the standalone funnel-density texture and four ground-dust masks, adapts the standalone dust and debris animations, and reads the F0–F5 profile heights and widths, shape radii, and wedge eye radius. The walk-in wedge uses the game's wedge dimensions at F5 and scales them down for lower ratings. Source templates and asset generators live in `tools/storm-disasters/`, including `Weather.csx.in` for runtime weather and `weather-assets.cjs` for the baked masks and audio. Edit these sources rather than the generated assets. Regenerate the add-on files before committing a shared change, and sync before publishing the separately versioned add-on.

From the repository root, `node --test Tests/StormDisastersSync.test.cjs` checks synchronization and `node Addons/StormDisasters/Tests/check-layout.cjs` validates all 36 entries. On Flatgrass, run `Tests/SpawnlistSmoke.cs.txt` through the editor's `run_csharp` tool to verify the visible native spawnlist, section headings, and all 36 links. `Tests/VolumeSmoke.cs.txt` checks all six shapes without touching the player's undo stack. In your own Play session, run `Tests/FlatgrassSpawnSmoke.cs.txt` to exercise stock spawn and undo for the original three presets. Do not run that test while someone else is spawning items in the same session.
